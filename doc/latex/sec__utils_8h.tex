\doxysubsection{Detailed Description}
Utilities for the security layer. 

This header declares utility functions shared by the security layer. It includes helpers for converting hexadecimal strings into byte vectors and small generic macros used while processing cryptographic input data. These utilities support configuration parsing and internal data handling.

Decodes a hexadecimal string into a byte vector. 

The input can optionally begin with the prefixes {\ttfamily 0x} or {\ttfamily 0X}. After an optional prefix, the string must contain an even number of valid hexadecimal characters.

\end{DoxyReturn}
