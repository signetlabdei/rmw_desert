Detailed Description

Utilities for the security layer.

This header declares utility functions shared by the security layer. It includes helpers for converting hexadecimal strings into byte vectors and small generic macros used while processing cryptographic input data. These utilities support configuration parsing and internal data handling.

bool decode_hex ( const std::string & hex,
std::vector< uint8_t > & out )

Decodes a hexadecimal string into a byte vector.

The input can optionally begin with the prefixes 0x or 0X. After an optional prefix, the string must contain an even number of valid hexadecimal characters.

Parameters
hexString containing hexadecimal byte values.
outOutput vector receiving the decoded bytes.
Returns
true if the complete input is valid and has been decoded; false if the input has an odd length or contains non-hexadecimal characters.
Note
On failure, out is cleared.
