Decodes, authenticates, and decrypts a COSE message.

If stateless compression is enabled, the method first reconstructs the standard COSE serialization. It then decrypts the message using the receiver key and copies the recovered plaintext to data.

Parameters
dataBuffer containing the received COSE message. On success, it is overwritten with the plaintext payload.
data_lenLength of the received message in bytes.
data_max_lenTotal capacity of data in bytes.
new_data_lenOutput length of the recovered plaintext in bytes.
Returns
OK on success; UNWRAP_ERROR if parsing, authentication, or decryption fails; otherwise a specific processing error.

Encrypts and serializes an application payload as a COSE message.

Generates a Partial IV from the current sender sequence number, adds it as an unprotected COSE header, encrypts the payload with the sender key, and optionally applies the stateless COSE compression format.

On success, the sender sequence number is incremented.

Parameters
dataBuffer containing the plaintext payload and receiving output.
data_lenLength of the plaintext payload in bytes.
data_max_lenTotal capacity of data in bytes.
cose_ptrOutput pointer to the beginning of the encoded message.
cose_lenOutput length of the encoded COSE message in bytes.
Returns
OK on success; otherwise an error describing the failed step.
Note
The caller must ensure that data has sufficient capacity for the resulting serialized message.
