Detailed Description

Class used to handle the encryption of the stream.

This header declares the security layer used to protect application data. It derives sender and receiver contexts, builds nonces, and performs COSE wrapping and unwrapping of payloads using the selected AEAD and KDF schemes. It also manages key material, identifiers, and serialization buffers.
